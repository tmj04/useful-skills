## 封面风格模板（6 种）

### 1. 大字报风格 (big-text)

**适用场景**: 干货分享、攻略、清单类内容

**Prompt 要点**:
- 纯色或渐变背景（莫兰迪色系、奶油色、浅灰）
- 超大加粗中文标题居中，占据画面 60-80%
- 简洁排版，无多余装饰
- 配色建议：白底黑字、米黄底深棕字、浅灰底深蓝字

**Prompt 示例**:
```
小红书封面图，大字报风格，纯色奶油色背景，超大加粗的"xxx"中文标题居中显示，简洁排版，莫兰迪配色，专业感，高清
```

---

### 2. 杂志风 (magazine)

**适用场景**: 穿搭、美妆、生活方式、探店

**Prompt 要点**:
- 杂志封面排版布局
- 主图占据大部分画面（产品/人物/场景）
- 标题优雅叠加在图片上（非遮挡主体）
- 时尚感、精致感、高质感
- 可适当加入英文装饰文字

**Prompt 示例**:
```
小红书封面图，时尚杂志封面风格，精美的 xxx 作为主图占据大部分画面，优雅的中文标题"xxx"艺术字体叠加在顶部，时尚感，高级感，柔光效果，高清
```

---

### 3. 知识卡片风格 (knowledge)

**适用场景**: 教程、科普、步骤讲解、数据对比

**Prompt 要点**:
- 干净背景（白色/浅灰/淡彩）
- 结构化信息展示
- 编号列表 + 图标辅助
- 标题醒目在顶部
- 类似 Notion/笔记风格

**Prompt 示例**:
```
小红书封面图，知识卡片风格，干净的浅色背景，标题"xxx"在顶部醒目显示，下方是结构化的步骤/要点展示，带有数字编号和小图标，专业清晰，易于阅读，高清
```

---

### 4. 对比图风格 (comparison)

**适用场景**: 测评、红黑榜、好物推荐、踩坑避雷

**Prompt 要点**:
- 左右分栏或上下分栏
- 左侧/上方用红色系标识"不推荐/踩雷"
- 右侧/下方用绿色系标识"推荐/种草"
- 清晰标注对比项
- 可使用箭头、勾选、叉号等视觉元素

**Prompt 示例**:
```
小红书封面图，对比图风格，左右分栏布局，左侧红色背景显示"❌避坑"字样和不好的 xx，右侧绿色背景显示"✅推荐"字样和好的 xx，对比鲜明，一目了然，高清
```

---

### 5. 拼贴手账风 (collage)

**适用场景**: 旅行记录、日常分享、购物开箱

**Prompt 要点**:
- 多图拼贴布局
- 手绘装饰元素（贴纸、涂鸦、边框）
- 活泼色彩搭配
- 可加入日期、地点等小标签
- 温暖治愈感

**Prompt 示例**:
```
小红书封面图，手账拼贴风格，多个 xxx 照片以不规则方式拼贴，手绘装饰元素如星星花朵边框，温暖的配色，活泼可爱，有生活气息，高清
```

---

### 6. 简约 INS 风 (minimal)

**适用场景**: 家居、咖啡、文艺、极简生活

**Prompt 要点**:
- 大量留白空间
- 低饱和度柔和配色
- 极简排版
- 精致的细节
- 高级感和呼吸感

**Prompt 示例**:
```
小红书封面图，INS 简约风格，大量留白的浅色系背景，精致的 xxx 小物件摆放在角落，极简排版，低饱和度配色，高级感，温馨治愈，高清
```

## 爆款标题公式（6 种）

### 1. 数字 + 关键词 + 情绪词
> "5 个让我回购 10 次的平价好物!!"
> "3 款面霜实测，第 2 个真的绝了!"

### 2. 疑问/反问式
> "为什么没人早点告诉我这个方法？"
> "这真的是我能拥有的吗？！"

### 3. 对比/转折式
> "月薪 3000 vs 月薪 30000 的护肤差距"
> "买之前 VS 买之后，我后悔了..."

### 4. 身份代入式
> "作为干皮星人，这些面霜我闭眼入"
> "小个子姐妹必看！这条裤子太显高了"

### 5. 紧迫感/稀缺性
> "再不知道就晚了！2025 必囤清单"
> "限量 100 件！手慢无的宝藏单品"

### 6. 避雷/踩坑式
> "千万别买！这 5 款网红产品全是智商税"
> "血泪教训！这些坑我替你踩过了"

## 正文结构模板

```markdown
【开头 Hook】🔥
一句话抓住注意力，点出核心痛点或亮点

【分段正文】
💡 第一点/体验 1
[emoji] 具体内容，口语化表达，像跟闺蜜聊天一样

✨ 第二点/体验 2
[emoji] 具体内容，个人感受为主，适当夸张但真实

💕 第三点/总结
[emoji] 总结推荐或号召互动

【话题标签】
#话题 1 #话题 2 #话题 3 ... (8-12 个)
```

## Emoji 使用规范

### 强调类 🔥❗‼️⚡💯
- 用在重要观点开头
- 吸引注意力的关键句

### 推荐类 ✅💕❤️🌟⭐👍
- 表示推荐/喜爱
- 正面评价

### 避雷类 ❌⚠️🚫💀
- 表示不推荐/警告
- 负面评价

### 装饰类 🌈🎀🧸🌸✨💫
- 增加氛围感
- 段落间过渡

### 分类类 📌📝📖🔍💡
- 内容分区
- 引导阅读

**使用原则**: 每段 1-2 个 emoji，风格与内容匹配，不过度堆砌

### 分析结果时提取的信息

1. **爆款标题共性**
   - 用了什么标题公式
   - 包含了哪些情绪词
   - 有没有特殊符号（!!!、「」）

2. **内容结构**
   - 开头是怎么 hook 的

   - 有没有新兴的热点标签

4. **流行趋势**
   - 当前平台流行的内容形式
   - 最近的热点话题

## 轮播图设计要点

### 多张图的一致性

- 统一的配色方案
- 相同风格的字体和字号
- 一致的版式结构
- 统一的装饰元素（如有）

### 页码标识

每张图都应有清晰的页码提示：
- "P1/5" / "1/5" / "Page 1 of 5"
- 位置统一（建议右下角或顶部中央）
- 字体大小适中，不喧宾夺主

### 内容分配建议

| 页码 | 内容类型 | 说明 |
|------|----------|------|
| P1 | 封面图 | AI 生成，吸引眼球，包含标题 |
| P2 | 核心卖点 1 | 图文结合，重点突出 |
| P3 | 核心卖点 2 | 同上 |
| P4 | 细节展示/对比 | 素材原图或 AI 增强 |
| P5 | 总结/号召 | 行动引导，强化记忆 |
